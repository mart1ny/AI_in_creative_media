## Воспроизведение

Зависимости: Python 3, PyTorch, NumPy, Pillow. Из корня репозитория:

```sh
python3 -u LR11/src/execute_lr11.py
```

Для Engee нужно загрузить каталог в отдельную рабочую директорию и вызвать этот Python-сценарий через установленный интерпретатор Python. Код не требует CUDA; число потоков задаётся LAB_THREADS, по умолчанию 4. Повторный запуск перезаписывает артефакты, поэтому используйте копию каталога. Истории потерь записаны для каждого seed, снимки по шагам и финальные 32 образца - для seed101.

Файлы `reference/` - предоставленные пользователем результаты преподавателя. Его демонстрация относится к варианту1 и не выдаётся за результат варианта3. Самостоятельный прогон находится в `artifacts/`.

Протокол гипотезы перед серией Engee и сведения о предварительной пробе описаны в [journal.md](journal.md). Метрика seconds для seed101 включает callbacks сохранения снимков. Для воспроизведения анализа и PDF: `python3 LR11/scripts/build_deliverables.py` (дополнительно ReportLab, Matplotlib, nbformat, шрифт Arial macOS).
