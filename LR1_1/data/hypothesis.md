# Предварительная запись гипотезы

Дата записи: 24.09.2026, 13:39 UTC. Исполнитель: Власюк Данил Витальевич.

Вариант 3: облачное небо как фон афиши; изменяемый фактор — шаг решётки `cell` с 32 до 64 пикселей. Остальные параметры, в том числе размер 96 × 96 пикселей, фиксируются. Серия: seed 101, 102, 103, 104, 105.

Гипотеза до запуска: увеличение шага решётки укрупнит облачные пятна и уменьшит среднюю граничную энергию, потому что переходы яркости растянутся на большее расстояние. Для средней яркости, контраста и энтропии направление заранее не задаю: при небольшом числе узлов результат зависит от конкретных seed. Проверю, превысит ли изменение каждой из четырёх метрик разброс базовой серии.

Порог решения зафиксирован до запуска: эффект по метрике считаю обнаруженным, если `|Δ| > 2 × s_base`, где `s_base` — выборочное стандартное отклонение пяти базовых запусков. Это учебный порог, а не статистический тест. Отсутствие обнаруженного эффекта при n = 5 не означает отсутствия влияния фактора.

Критерий воспроизводимости: для последовательности seed 101, 101, 1101, 101 отпечатки полных массивов пикселей должны дать `true, true, false, true` для `EQ_1_2`, `EQ_1_4`, `EQ_1_3`, `EQ_2_4`.
