## Повторение

В Engee загрузите `src/LR03_3.jl` и `src/lab03_lib.jl` в одну папку, выполните `include("LR03_3.jl")`. Пакеты Images и Plots уже доступны в использованной среде. Скрипт создаёт `artifacts/` рядом с исходниками. Для сохранённого ngscript облачный путь — `/user/AI_in_creative_media/LR03/LR03_3.jl`; при размещении в другой папке измените строку include.

Локальная независимая проверка из LR3 (Python 3.10+, стандартная библиотека):

```bash
python3 scripts/verify_results.py
```

Повторная сборка паспорта: Python 3.11+ (`tomllib`). Для Word нужен python-docx; для оформления сравнительных рисунков — matplotlib, numpy, Pillow (фактическая версия matplotlib 3.10.8). Это зависимости оформления, а не расчёта в Engee. Оригинальный график Engee сохранён отдельно; рисунки сравнения построены по скачанным PNG и CSV.

Метаданные Engee автоматически указывают IJulia 1.9.3. Фактические VERSION и versioninfo подтверждают Julia 1.12.4; исходный скачанный ngscript сохранён без изменения. Метрики рассчитаны до экспорта PNG на Float64. Гистограммная энтропия не является мерой пространственного качества. Учебный критерий 2s не является формальным тестом с p-значением.

Обновление оформления Markdown без пересоздания Word:

```bash
python3 scripts/format_markdown_report.py
```

Пересборка архива и проверка его контрольных сумм:

```bash
python3 scripts/package_submission.py
```
