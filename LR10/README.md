Две выполненные ячейки ноутбука читают паспорт и фактический журнал с итогами; полный код сценария включён в ноутбук с пояснениями. Повторное открытие ноутбука не запускает генерацию заново.

aMUSEd получила более высокий CLIP-score, но потребовала в среднем 45,24 с против 25,42 с у SD-Turbo. Слепой выбор ИИ-ассистента — 4:1 в пользу SD-Turbo. Пять пар и один ИИ-оценщик не доказывают общего превосходства модели; ограничения и расхождение метрик с визуальной оценкой разобраны в отчёте.

## Воспроизведение

Загрузить содержимое в `/user/AI_in_creative_media/LR10` в Engee. Сохранённый сценарий рассчитан на окружение Python из паспорта: torch 2.4.1+cpu, diffusers 0.32.2, transformers 4.57.6, numpy 2.1.3, scipy 1.15.2, Pillow 11.1.0. Для повторной генерации из этой директории выполнить в командном окне Engee:

```julia
cd("/user/AI_in_creative_media/LR10")
run(`/user/.user_venvs/py3.11/bin/python3 -u src/execute_lr10.py`)
```

Повторная генерация перезапишет артефакты, поэтому для нового эксперимента следует использовать копию директории. Сохранённые ячейки относятся к исходному прогону. Начальный сценарий в Engee находился в корне рабочей директории; в комплекте он размещён в `src/`.

## Проверка и сборка

```sh
python3 LR10/scripts/verify_results.py
python3 LR10/scripts/package_submission.py
```

Проверяются SHA-256 исходного сценария, 10 PNG, метрики edge/contrast и агрегирование пяти показателей. CLIP и замеры времени независимо повторно не запускались. Вывод проверки сохранён в [verification.txt](reports/verification.txt). SHA-256 файлов комплекта — в [manifest.json](reports/manifest.json).

`scripts/build_report.py` собирает PDF/Markdown (ReportLab и Arial macOS). `scripts/build_notebook.py` создаёт начальную заготовку без результатов; не следует запускать его поверх сохранённого выполненного ноутбука.
