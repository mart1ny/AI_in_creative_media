## Повторная проверка

Из папки LR2 выполните:

```bash
python3 scripts/verify_submission.py
```

Требуется Python 3.10+; внешние пакеты для проверки не нужны. Скрипт создаёт вариант во временной папке, сверяет исходные CSV/JSON, повторяет аудит, проверяет покрытие решений, обязательные категории, разделы карточек, хеши входов и PASS реестра. Финальные документы не меняются; обновляется `reports/verification.json`.

Полные первоначальные команды и выводы находятся в журнале и отчёте. Пять `src/lab02_*.py` предоставлены преподавателем и сохранены без изменений. `inputs/` содержит паспорт и результаты ЛР 1 плюс исходный генератор для проверки версии. Скрипты в `scripts/` оформляют решения, документ и проверки. Для повторного построения Word дополнительно требуется python-docx и последующая визуальная проверка; текущий Word уже проверен рендером.
