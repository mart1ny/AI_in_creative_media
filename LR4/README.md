## Повторение

В Engee загрузить `notebooks/LR04_3.ngscript`, `src/lab03_lib.jl`, `src/lab04_lib.jl` и `data/hypothesis.md` в одну папку LR04. Выполнить все ячейки сверху вниз. Если выбрана другая папка, перед запуском перейти в неё командой `cd` или изменить `LR04_ROOT` в первой ячейке кода. Ноутбук создаёт `artifacts/` и `LR04_variant3_results.tar`.

Независимая проверка сохранённых результатов, Python 3.11+ без сторонних пакетов:

```bash
python3 scripts/verify_results.py
```

Экспорт Markdown и сборка комплекта:

```bash
python3 scripts/export_markdown.py
python3 scripts/package_submission.py
```

`scripts/build_notebook.py` создаёт **неисполненный** исходный шаблон в `notebooks/prepared/` и сохраняет скачанные исполненные файлы. Не использовать исходный шаблон вместо готового ноутбука для сдачи.
