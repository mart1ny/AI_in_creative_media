Полностью выполнены оба приложенных демо и индивидуальный вариант на seed 101–105. Исходники не менялись: их SHA-256 проверены. Гипотеза и допуски записаны до генерации. Проверены guidance 0/1/3 и статус CFG.

Главный результат: среднее время выросло 0,3453 → 0,7324 с (+112,1%), CLIP снизился 30,7979 → 29,1852 (−1,6127). Для CLIP практический допуск превышен, а критерий 2s не выполнен; критерии действительно расходятся. Границы и контраст нейтральны по допуску ±10%. В сравнительной паре seed 101 при 768 заметно дублирование механических частей. Отдельная механическая рука не стала более ясным главным объектом; соответствие брифу частичное в обоих режимах. В этой серии увеличение размера не оправдано.
